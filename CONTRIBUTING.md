# Contributing to Back To Life Website

Thank you for considering contributing! 🚀

We are a small team working on revamping the OSW website with futuristic UI/UX. Contributions, suggestions, and bug fixes are welcome.

## 📝 How to Contribute
1. **Fork** the repository
2. Create a new branch:
   ```bash
   git checkout -b feature-name
   ```
3. Make your changes (HTML/CSS/JS only)
4. Commit with a meaningful message:
   ```bash
   git commit -m "Add animated team section"
   ```
5. Push your branch:
   ```bash
   git push origin feature-name
   ```
6. Open a **Pull Request** into `osw-backtolife-website`

## 🌌 Guidelines
- Keep code clean, well-commented, and readable.
- Use **Vanilla JS, CSS, HTML only** — no external frameworks.
- Test responsiveness (mobile, tablet, desktop).
- Follow existing dark/light theme structure.

## 🤝 Code of Conduct
We follow the standard [Contributor Covenant](https://www.contributor-covenant.org/). Be respectful and collaborative.

## 📧 Questions?
Open an issue or reach out to the team via the contact section on the site.
